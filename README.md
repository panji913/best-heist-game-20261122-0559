You are Rook, a thief with one night, three rooms and a very loud alarm. Slip past the guards and their vision cones, dodge the sweeping security cameras, grab every piece of loot, then reach the green EXIT before the alarm hits 100%.

Three original rooms — The Ember Gallery, The Vault Hall, The Crown Room — with patrolling guards that chase you when they spot you, wall cameras that sweep the floor, a coin toss to lure guards away, and a sneak mode that makes you harder to see. Every piece of art, every sound and every name is original, made for this game.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. No build step, no network — the game is plain static files under `game/`.

Controls: WASD / arrows — move · SHIFT — sneak · mouse click — toss a coin · E — grab loot · P — pause · M — mute · R — restart the room.
